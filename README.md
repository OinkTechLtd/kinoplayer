## О проекте

**KinoPlayer** — полноценный пиратский плеер  с интерфейсом в стиле kinobox
- 🔍 Поиск через **StreamLIVETV API** (Фильмы и сериалы)
- 🎨 Интерфейс в стиле **kinobox**

## Быстрый старт

```bash
# Клонировать
git clone https://github.com/your-username/kinoplayer.git
cd kinoplayer

# Открыть в браузере
# Вариант 1: просто откройте index.html
open index.html

# Вариант 2: через VS Code Live Server
code .
# Установите расширение "Live Server" → правая кнопка на index.html → "Open with Live Server"

# Вариант 3: через Python
python3 -m http.server 8080
# → http://localhost:8080
```
